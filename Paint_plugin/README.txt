Этот плагин для SCP: Secret Laboratory на базе EXILED позволит раскрыть творческий потенциал игроков вашего сервера.

С его помощью вы сможете превратить обычный игровой объект в полноценный холст для рисования, а игроки получат набор инструментов для создания собственных произведений прямо во время игры.

Основные возможности:

• Создание полноценного «холста» на основе матрицы примитивов и специального кастомного предмета, позволяющего рисовать непосредственно на его поверхности.

• Отображение изображений и GIF на холсте по URL-адресу файла.

• Набор инструментов для удобного рисования: пипетка, ластик, изменение размера мазка и выбор цвета по HEX-коду.

• Тонкая настройка параметров плагина, позволяющая адаптировать его под особенности вашего сервера и оптимизировать производительность.

Все доступные команды можно посмотреть в консоли SCP: Secret Laboratory с помощью команды ".canvas_help".

Команды плагина работают через стандартную консоль SCP: Secret Laboratory и разделены на две категории: доступные обычным игрокам и доступные только администраторам.

Создавайте, рисуйте, экспериментируйте — и дайте своим игрокам возможность оставить на сервере что-нибудь своё.
